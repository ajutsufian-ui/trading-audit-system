# AuditOS - Visual Trading Audit System

Prototype v0.1 of a trading audit system: live portfolio valuation, market regime detection (EMA trend + 100-day filter), auditable trade log with stop-discipline verification, and risk metrics (PF, drawdown, losing streaks).

Live demo: https://ajutsufian-ui.github.io/trading-audit-system/

- No build step, no dependencies: open index.html or serve statically.
- Prices via CoinGecko public API.
